# Scorpion Cursor 🦂

An interactive, animated skeletal scorpion that follows the mouse cursor, built with Python and Pygame.

## Features
- Procedural scorpion animation
- Mouse tracking
- Articulated legs and pincers
- Curved, segmented tail
- Glowing silver wireframe
- Animated background particles
- Screenshot capture
- Pause and resume controls

## Requirements
- Python 3
- Pygame 2.6.1 or later

## Installation

```bash
python -m pip install -r requirements.txt
